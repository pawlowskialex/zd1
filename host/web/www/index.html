Connect

    

      
A Zeppelin Air with our software: plug it into this computer with a USB cable, or reach it on
         your network. The page talks to the speaker itself: no account, no cloud.

      
This browser has no WebUSB: open the page in Chrome, Edge, Brave or Opera.

      

        pick “Zeppelin Air” in the browser's list

      

        
        
        
      

      

        How the network connection works
        
The Network panel shows the speaker's address once connected over USB. The browser asks once to
           let this page reach devices on your network; the speaker asks for ON/OFF held 5 s the first time, and knows
           this browser from then on. Over the network the page does everything but the main board's firmware and the
           module's boot image, which go over USB (the main board follows its system by itself).

Help

    

      

        It doesn't appear in the browser's list
        
    
          
  • B&W's software never appears: start the speaker in its bootloader (Install, above).
    • 
          
  • Use a USB cable that carries data (some only charge), straight to the computer.
    • 
          
  • The browser: Chrome, Edge, Brave or Opera, on a desktop or on Android. Safari and Firefox have no WebUSB.
    • 
          
  • Windows: our firmware brings its own driver setting (WinUSB). B&W's bootloader doesn't: for it (the
              speaker in its bootloader, "AT32UC3A" in the Device Manager), install WinUSB once with
              Zadig (Options, List All Devices). Our firmware of a release before
              this one wants the same for its "Interface 3" only, never the whole speaker: sound and keys keep
              Windows' own drivers.
    • 
          
  • Linux: give your user the device with this rule, then plug the speaker in again:
            
    sudo tee /etc/udev/rules.d/70-zd1.rules <<'EOF'
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2fe0", TAG+="uaccess"
SUBSYSTEM=="usb", ATTR{idVendor}=="03eb", ATTR{idProduct}=="2ff8", TAG+="uaccess"
EOF
sudo udevadm control --reload-rules
    • 
        

      

      

        It stopped during an update, or it doesn't start
        
It waits in its bootloader: connect and pick the bootloader. The page shows how far its firmware got and
           offers a repair, or a backup this browser kept. If it isn't listed, hold ON/OFF while plugging its power in.

Red, breathing

Purple, flashing

Amber, flashing

        Back to B&W's software
        
The Zeppelin Air: connect to its bootloader (Install, above) and choose “Back to B&W's software” there,
           with B&W's update file and its main board's firmware, or a backup this page kept. The Lightning model:
           B&W's own file through its updater, the way the install went (zd1lv20435.fw,
           in the repository's blobs/zd1l).

Known networks

The passphrase stays on this computer: the page derives the WPA2 key from it, and only the key
             goes to the speaker.

        

        
The speaker's radio is 802.11b/g: 2.4 GHz networks only. WPA2 and WPA2/WPA3 networks join;
           WPA3-only networks can't (its driver has no WPA3).
